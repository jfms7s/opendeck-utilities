Action

1/3 → 1/4 → 1/5, then back to 1/3. Columns that were dragged a little off a layout are put back first.

Needs KDE Plasma 6 on Linux (not expected to work from the Flatpak OpenDeck). A press sets the tile columns of the screen and virtual desktop in use. The key flashes an alert only if KWin can't be reached or won't load or run the script; a problem inside KWin, such as a column that can't shrink because a window in it is too wide, only goes to KWin's log (journalctl --user, lines starting opendeck-utilities layout:).
