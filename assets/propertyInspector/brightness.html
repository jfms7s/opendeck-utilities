Action

Used by "Set to value".

Presets

Pressing the dial toggles between them.

Touch strip

Holding the strip always toggles between the presets.

Step

Rotating the dial steps the brightness by this much.

Changes go through opendeck --process-message (OpenDeck 2.14.0 tested); if one doesn't take effect the control flashes an alert and the plugin log says why.

Schedule

Plugin-wide, for every Brightness control and whatever profile is shown. Leave a time empty to turn it off. Turning the dial in between is kept until the next scheduled time.
